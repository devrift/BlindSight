Core System Architecture

Three Integrated Subsystems

Engineered with zero bloat. Every component serves an essential function in safety, awareness, and independence.

1. Android Companion App

Native Kotlin & Jetpack Compose application designed strictly for accessibility.

  • Voice-First: Wake word detection + 112px accessible push-to-talk button.
  • Scene Describer: Spoken commands capture camera frames for situational descriptions.
  • Personal Memory Bank: Remembers key facts, places, and door locations offline.
  • Obstacle Radar: Real-time distance visualization with authentic warning earcons.
  • Multi-Language: Instant switching between 7 supported languages.

2. ESP32 Reflex Hardware

Firmware in firmware/esp32_main/ delivering instantaneous physical obstacle reflexes.

  • 3x HC-SR04 Sonar: Left, Center, and Right obstacle sensors sweep continuously.
  • PCM5102 I2S DAC: Zero-latency stereo audio alerts played directly into earphones.
  • Push-to-Talk Pin: Physical button on GPIO 32 for tactile interaction.
  • Fail Loudly: Hardware reflex operates autonomously even if phones or WiFi disconnect.
  • ESP32-CAM: Optional compact camera module streaming video over WiFi.

3. Edge Server Gateway

Python Flask service in edge_server/ providing speech and multimodal intelligence.

  • Unified API: /api/chat, /api/voice, /api/upload-frame, /api/tts.
  • Multimodal Vision: Rapid image inspection for obstacles, paths, text, and signs.
  • Dynamic Fallbacks: Graceful degradation ensures voice queries always receive prompt answers.
  • No Fluff: Direct, helpful, concise navigation assistance.

Android Installation

Install in 3 Simple Steps

BlindSight is distributed as a direct APK. Follow these steps to install and start navigating.

1

Download the APK

Tap the Download APK button or scan the QR code above on your Android smartphone (compatible with Android 7.0 through 15).

2

Allow Unknown Sources

When Android displays a prompt, tap Settings and toggle Allow from this source for your browser or file manager.

3

Open & Speak

Grant Microphone and Camera permissions when asked. Tap the center 112px mic button or say "BlindSight" to start hands-free navigation.
