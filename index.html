Core Philosophy: Fail Loudly, Never Optimistically #

Blind and low-vision pedestrians face hazards from low wires, drop-offs, and quiet electric vehicles. Traditional electronic aids cost thousands of dollars, while smartphone apps frequently freeze silently or hallucinate descriptions.

The Core Tenet: A mobility aid must fail loudly, never optimistically. Every tier reports its exact live condition. No endpoint ever synthesizes placeholder data, serves a cached expired JPEG, or pretends an offline service is healthy. A missing neural model, dead sensor, or lost network generates an immediate, honest spoken alert.

Three Golden Engineering Constraints:

  • Zero-cloud collision reflex: If cloud servers go down or cellular signal drops, the ultrasonic stop and steer reflex functions with 100% autonomy on raw hardware.
  • No silent failures: If an audio buffer underflows or a sensor drops, the watchdog trips and announces the failure state.
  • Accessible by design: WCAG AAA compliant palette (#05070c background, #f59e0b high-visibility amber), touch targets ≥56px (primary mic button 112px), single assertive screen-reader live region.

Quickstart Guide #

Deploy the BlindSight gateway in three simple steps across Windows or Linux environments:

Clone the repository and run the local edge server:

git clone https://github.com/devrift/blindsight.git
cd blindsight
python edge_server/server.py

The edge gateway starts on port 5000 and serves speech, vision, and navigation telemetry.

On any Linux distribution or SBC:

git clone https://github.com/devrift/blindsight.git
cd blindsight
pip install -r edge_server/requirements.txt
python edge_server/server.py

Download the pre-compiled native APK directly onto your phone, allow installation from Unknown Sources, and open BlindSight to navigate.

Android Companion Features #

Key Advantages of the Native Companion:

  • Default Digital Assistant: Set BlindSight as your Android default voice assistant in system settings for instant home-button & gesture activation.
  • Safe Whole-Phone Control: Set alarms, countdown timers, calendar reminders, place phone calls, and launch apps hands-free.
  • Giant Accessible Push-to-Talk: High-visibility tactile microphone surface with confirmation haptics.
  • Wake Word & Hands-Free: Continuous background listener responds to "BlindSight" or "hey BlindSight".
  • Multimodal Scene Camera: Instant spoken descriptions of obstacles, doors, and pathways.
  • Offline Personal Memory Bank: Securely remembers names, locations, and personal items offline.

Three-Tier Safety Architecture #

The system partitions responsibilities so that critical obstacle detection never depends on internet access:

Tier 0 • Critical Reflex

ESP32 Hardware

3x HC-SR04 ultrasonic array continuously scanning Left, Center, and Right. Direct hardware audio reflexes via PCM5102 I2S DAC.

Tier 1 • Edge Gateway

Local Intelligence Hub

Python Flask service handling speech-to-text, camera frame analysis, and contextual dialogue with instant local earcons.

Tier 2 • Companion Shell

Android App (v1.0.0)

Autonomous voice companion with multi-mic ENC noise cancellation, real-time multimodal vision, and offline ultrasonic reflex protection.

Ultrasonic Reflex Thresholds

< 25 cm Critical Stop Alert (stop.wav)
25 – 45 cm Steering Direction (left.wav / right.wav)
< 100 cm Caution Guidance (careful.wav)
≥ 100 cm Path Clear Confirmation (clear.wav)

Easy Setup Guide • Connect in 4 Simple Steps #

You do not need any coding or technical knowledge to get started with BlindSight. Everything connects automatically:

Step 1 Install the App

Download BlindSight-testing.apk directly to your Android phone from this page or by scanning the QR code with your camera.

Step 2 Allow Permissions

Open BlindSight and grant Microphone and Camera permissions. Tap Settings and allow "Install unknown apps" so the app updates seamlessly in the future.

Step 3 Say "Hey Assistant"

Speak naturally anytime hands-free. Say "Hey Assistant" or "Hey BlindSight" to ask questions, check time, or inspect what is ahead.

Step 4 Use Tactile Gestures

Tap once to talk, tap twice to describe your surroundings, or tap three times to read text. All gestures can be customized in the in-app Settings.

Zero Configuration Required

BlindSight works immediately out of the box using your phone camera and on-device intelligence. No gateway IP setup, complex wiring, or terminal commands are necessary.

Voice Commands & Memory Bank #

BlindSight operates fully through natural spoken commands:

Intent Example Voice Command Response Behavior
Wake Word "hey BlindSight" / "ok BlindSight" Plays wake chime and begins listening hands-free
Multimodal Vision "describe" / "what is around me" Captures camera frame and speaks situational description
Store Fact "remember that my keys are on the desk" Saves fact to persistent on-device memory bank
Recall Memory "what do you remember?" / "where are my keys" Queries memory bank and recites saved facts
Forget Fact "forget my keys" / "forget everything" Removes specific fact or clears memory bank
Language Switch "language hindi" / "switch to spanish" Instantly switches speech synthesis and recognition

Limitations & Safety Notes #

In alignment with the principle of failing loudly:

  • Cane Replacement Mission: BlindSight is engineered as an advanced electronic replacement for traditional white canes, utilizing high-precision ultrasonic reflex audio (<25 cm stop protection) paired with live multimodal vision that perceives head-height hazards, stairs, doors, and path clearance.
  • Ultrasonic Material Factors: Extremely soft acoustic-absorbing fabrics (e.g. heavy wool coats) can soften 40 kHz echoes.
  • Autonomous Reflex: Hardware ultrasonic alerts on the ESP32 operate 100% offline and will alert you even if phone battery or Wi-Fi runs out.
